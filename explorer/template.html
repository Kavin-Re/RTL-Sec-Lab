Trace explorer: simulated power traces and CPA peaks

Simulation only. Leakage model is ASSUMED: each sample = Hamming weight of one byte + Gaussian noise. Target: stage 1 of the first SipRound, v3 = k1 ^ C3 ^ m. No device was measured.

CPA: correlation for each of the 256 key guesses

Correlation of the true guess and the best wrong guess as traces accumulate

Signs: guesses that differ from the true byte in only a few bits show large ghost correlations, and the bitwise complement of the true byte correlates with about -r, so rank by the signed value (second order: by the negated value). Peak ratio = best / second-best |r|.
